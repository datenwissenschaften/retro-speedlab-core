# Stream ideas

Ideas for the live stream view that are not built yet.

## Update announcements

When a new release is loaded, show a banner such as "New game package 2026.09.28-2 — now knows
where the snake really is". The deploy script already stamps every deploy with a CalVer release;
it would additionally take a one-line release note, publish it next to `ui.release`, and the
stream would show it for the first minute after the reload.
